# 🛒 JS e-Market  

**JS e-Market** — это учебный проект интернет-магазина, реализованный на JavaScript.
В проекте предусмотрены фильтрация товаров, добавление/редактирование товаров, управление корзиной и сохранение данных в LocalStorage.  

## 🚀 Функциональность  

### 📌 Работа с товарами  
- Отображение списка товаров  
- Фильтрация товаров по категориям  
- Возможность добавления новых товаров  
- Возможность редактирования информации о товаре  
- Сохранение изменений в LocalStorage  

### 🛍 Управление корзиной  
- Добавление товаров в корзину  
- Подсчёт итоговой суммы заказа  
- Удаление товаров из корзины  
- Сохранение состояния корзины после перезагрузки страницы  

## 🛠 Используемые технологии  

- **HTML, CSS** — базовая структура и стили  
- **Vanilla JavaScript (ES6+)** — динамическое управление контентом  
- **LocalStorage** — хранение данных о товарах и корзине  
- **DOM API** — манипуляции с элементами страницы
